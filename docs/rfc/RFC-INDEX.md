# Request for Comments Index

**Status:** Draft

**Owner:** Maintainers

**Last reviewed:** 2026-08-03

## Purpose

This index registers substantial proposals that remain open to review. An RFC is not an accepted decision, an implementation, or authorization to operate a production service. A material choice may require a later ADR before implementation.

The repository does not yet define a complete RFC lifecycle. Until it does, every RFC MUST state its status, open decisions, implementation state, and relationship to accepted ADRs.
